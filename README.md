# Reminder Bot

Телеграм-бот для напоминаний. Работает в личных сообщениях и в группах: у каждого чата
свой независимый список напоминаний. Умеет повторять напоминание, пока его не подтвердят,
и упоминать участников через `@username`.

## Возможности

- Напоминания в личке и в группах, уникальные для каждого чата. Нумерация тоже своя:
  в каждом чате `#1`, `#2`, `#3` независимо от других чатов.
- Разовые и повторяющиеся: каждый день, по будням, по выбранным дням недели, раз в месяц
  в заданное число (если в месяце меньше дней — последний день месяца).
- Подтверждение: под сообщением появляется кнопка «✅ Подтвердить». Если её не нажать,
  бот пришлёт напоминание повторно через заданное время (по умолчанию 10 минут, до 3 попыток).
  Подтвердить может любой участник чата.
- Упоминания участников: `@username` в тексте напоминания.
- Часовой пояс на каждый чат (по умолчанию `Europe/Moscow`).
- Все данные в SQLite, после рестарта напоминания не теряются.
- Планировщик — фоновый тик по базе, точность ±15 секунд.

## Быстрый старт

1. Получите токен у [@BotFather](https://t.me/BotFather): `/newbot`.
2. Включите бота в группе: добавьте его в чат. Privacy mode трогать не нужно —
   бот получает команды. Для тегов достаточно `@username` в тексте.
3. Создайте `.env` из примера и впишите токен:

   ```bash
   cp .env.example .env
   # отредактируйте .env
   ```

4. Установите зависимости и запустите:

   **Windows (PowerShell):**

   ```powershell
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   python run.py
   ```

   **Linux / macOS:**

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   python run.py
   ```

## Команды

| Команда | Описание |
| --- | --- |
| `/remind` | Создать напоминание (пошаговый диалог) |
| `/list` | Активные напоминания текущего чата |
| `/cancel <номер>` | Отменить напоминание (автор или админ чата) |
| `/timezone` | Показать/изменить часовой пояс чата |
| `/help` | Справка |

## Форматы времени

При создании разового напоминания можно писать:

- `через 10 минут`, `через 2 часа`, `через 3 дня`
- `завтра в 9:00`, `послезавтра в 18:30`
- `25.11 18:30`, `25.11.2026 09:00`
- `18:30` — сегодня, если время ещё не прошло, иначе завтра
- `25 ноября в 18:30` — запасной парсер (`dateparser`)

Для повторяющихся напоминаний время задаётся как `ЧЧ:ММ` (например, `09:00`)
или кнопкой быстрого выбора.

## Как работает подтверждение

1. В назначенное время бот отправляет сообщение с кнопкой «✅ Подтвердить».
2. Если кнопку не нажали за N минут, бот присылает повтор (`🔁 Повтор 2/3`).
3. После исчерпания попыток бот пишет, что напоминание пропущено.
4. Подтверждённое сообщение редактируется: кнопка исчезает, добавляется имя подтвердившего.

Повторяющиеся напоминания продолжают работать по расписанию независимо от подтверждений.

## Теги участников

Просто укажите `@username` в тексте — Telegram сделает упоминание кликабельным и уведомит
пользователя. Ограничение Telegram: пользователя без username так упомянуть нельзя.

## Деплой на сервер (Docker)

На сервере нужен только Docker. Скопируйте проект (например, `git clone`), создайте `.env`
с токеном, затем:

```bash
chmod +x deploy.sh
./deploy.sh
```

Скрипт соберёт образ, удалит старый контейнер и запустит новый с автоперезапуском.
База хранится в docker-томе `reminder_bot_data` и переживает обновления.

```bash
./deploy.sh          # сборка и запуск
./deploy.sh rebuild  # пересборка без кэша после обновления кода
./deploy.sh logs     # логи
./deploy.sh status   # состояние контейнера
./deploy.sh stop     # остановить (база сохраняется)
```

Обновление кода: `git pull && ./deploy.sh rebuild`.

## Ограничения

- Один процесс бота на одну базу (SQLite).
- Диалог создания не сохраняется при рестарте — уже созданные напоминания сохраняются.
- Точность срабатывания зависит от `TICK_SECONDS` (по умолчанию 15 секунд).
- Упоминать можно только пользователей с `@username`.
